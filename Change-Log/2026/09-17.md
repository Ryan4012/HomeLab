# September 17, 2026

## Worked On
- Worked on adding my raspberry pi to the k3s cluster.

## What I Did
- Added the Pi to the Ansible inventory under k3s_agents, alongside k3s-agent-01.
- Re-ran the existing k3s-install.yml playbook to trigger the k3s agent install and join on the Pi.

## Issues / Findings
- The k3s agent install failed on the Pi — missing cgroup memory controller support, which Raspberry Pi OS doesn't enable by default the way a standard Debian install does.
- Root cause: /boot/firmware/cmdline.txt didn't have cgroup_memory=1 cgroup_enable=memory set, so the kernel wasn't exposing the memory cgroup k3s needs to enforce resource limits.
- Added those parameters to cmdline.txt — requires a reboot to take effect, so didn't get to confirm the fix same-day.
